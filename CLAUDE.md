# Second Brain Agent — контекст для Claude

Персональный локальный AI-ассистент владельца репозитория. Полное проектирование —
в `docs/` (читать по номерам). **Текущий статус и отступления от плана —
`docs/06-roadmap.md`, чек-лист внизу** — всегда сверяйся с ним и обновляй его
при завершении спринта.

## Правила работы

- Язык общения с владельцем — русский. Комментарии в коде и docstrings — русские;
  сообщения коммитов — английские.
- Сначала проектирование, потом код. Спринт считается принятым только после
  живой проверки владельцем на его машине (Windows).
- Каждое изменение: тесты + ruff + mypy + import-linter зелёные → commit → push
  в ветку `claude/local-ai-second-brain-cdh5cn`. Проверяй код возврата pytest
  явно (pipe в tail скрывает падения).
- Не переписывать `config/local.yaml` (его нет в git — он на машине владельца:
  токен Telegram, allowed_roots, whitelist user id 909506738).
- Проектные доки (`docs/01`–`docs/06`, roadmap) править **обязательно** по ходу
  работы: чек-лист `docs/06-roadmap.md` обновлять при завершении спринта, архитектуру
  и сервисы — при отступлениях от плана. Это часть DoD, а не «по желанию».
- Учебные/справочные материалы, созданные вне проектного проектирования, —
  путеводитель `docs/00-guide.md` и его HTML-страница (артефакт) — обновлять и
  пересобирать **только по явному запросу владельца**, никогда по своей инициативе.

## Среда владельца (не предполагать иное)

- Windows, ноутбук **CPU-only**: i7-1165G7, 16 ГБ RAM, без дискретного GPU.
  Ответы модели — десятки секунд; промпты держать короткими (бюджеты в конфиге).
- Ollama на `localhost:11434`; роли моделей — `config/models.yaml`
  (chat: qwen2.5:7b-instruct, extraction/summarize: qwen2.5:3b-instruct).
- Владелец — не программист: инструкции ему давать пошагово, PowerShell-синтаксис.

## Выученные уроки (не повторять)

- qwen2.5 7B фабрикует ответы: списки файлов, отчёты о действиях, имитирует
  служебные форматы. Защиты уже встроены: маркеры 🔧, чистка служебных строк
  из контекста (`context.py`), принудительный tool_choice по темам, дедуп
  вызовов, `/audit`, `/new`. Новые фичи проектировать с этим же недоверием.
- Всё внешнее (FS-обход, LLM-запросы, инструменты) обязано иметь таймаут.
- Служебные обмены (`/команды`) не должны попадать в историю диалога.

## Быстрые команды

- Тесты и линтеры: `. .venv/bin/activate && pytest -q && ruff check . && mypy && lint-imports`
- Живой smoke без модели: `printf '/tools\n/quit\n' | python -m sba`
